# ConsultaFácil 
## Sistema Municipal de Agendamento e Gestão de Consultas Médicas 

### Sobre o projeto O ConsultaFácil é um protótipo acadêmico de sistema para facilitar o acesso da população aos serviços de saúde municipais, permitindo consultar especialidades, visualizar disponibilidade e solicitar agendamentos. 

### Problema Pessoas podem enfrentar filas presenciais e dificuldades para obter informações sobre vagas e horários de consultas. 

### Objetivo Organizar o processo de agendamento e oferecer informações claras sobre unidades, profissionais, especialidades e vagas. 

### Módulos previstos- Cadastro e acesso de pacientes- Pré-atendimento e registro de triagem profissional- Consulta de especialidades e profissionais- Consulta de unidades de saúde- Calendário e agendamento de consultas- Controle de vagas comuns e preferenciais- Confirmação, protocolo e histórico de agendamentos- Painel administrativo 

### Tecnologias previstas- Python- Programação Orientada a Objetos (POO)- SQLite- Padrão DAO- Git e GitHub
