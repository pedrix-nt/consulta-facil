# Funcionalidades do ConsultaFácil

O sistema será desenvolvido para facilitar o agendamento de consultas na rede pública de saúde.

## 1. Cadastro de usuários
Permitir que o cidadão realize seu cadastro e informe seus dados pessoais.

## 2. Triagem inicial
Apresentar perguntas básicas para identificar a necessidade do atendimento e orientar a escolha da especialidade.

## 3. Especialidades
Permitir a consulta das especialidades médicas e dos profissionais disponíveis.

## 4. Agendamento
Exibir datas e horários disponíveis para que o usuário escolha seu atendimento.

## 5. Controle de vagas
Apresentar a quantidade de vagas disponíveis, incluindo a organização de vagas preferenciais.

## 6. Confirmação
Após o agendamento, apresentar uma confirmação com a data, o horário e a especialidade escolhida.
