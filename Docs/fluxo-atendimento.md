# Fluxo de atendimento

O usuário seguirá as seguintes etapas dentro do sistema:

1. Acessar o ConsultaFácil.
2. Realizar o cadastro ou entrar na conta.
3. Iniciar a triagem inicial.
4. Consultar a especialidade indicada ou desejada.
5. Verificar os profissionais disponíveis.
6. Consultar os horários e as vagas.
7. Escolher o horário desejado.
8. Confirmar o agendamento.
9. Visualizar os dados da consulta agendada.

O sistema deverá apresentar uma mensagem de confirmação ao finalizar o processo.
